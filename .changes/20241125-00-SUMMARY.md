### 2. GitHub Workflow Conditional Release
**Document**: `20241124-02-WORKFLOW-CONDITIONAL-RELEASE.md`

**Changes:**
- Added change detection step in CI/CD
- Only creates release if build output changes
- Uses SHA-256 checksum comparison
- Downloads previous release for comparison

**Logic:**
```
1. Build all plugins
2. Package to dist/
3. Compare with previous release:
   ├─ No previous release → CREATE RELEASE
   ├─ Checksums identical → SKIP RELEASE
   └─ Checksums different → CREATE RELEASE
4. Upload artifact (always)
5. Create release (conditional)
```

**Benefits:**
- ✅ Avoids duplicate releases
- ✅ Saves resources
- ✅ Clear feedback
- ✅ Artifacts always saved (30 days)

## Build Process (Final)

### Step 1: Download Icon Sources
```bash
./scripts/download-azure-icons.sh
./scripts/download-m365-icons.sh
# ... (9 download scripts)
```

### Step 2: Prebuild Icons
```bash
cd src/prebuild
npm run build
# → icons.json
# → icons/*.svg
# → templates/icons-data.js
# → templates/ui-base.*
```

### Step 3: Build Plugins
```bash
cd src/figma/plugin && npm run build      # → out/
cd src/powerpoint/add-in && npm run build  # → out/
cd src/google-slides/addon && npm run build # → out/
cd src/drawio/iconlib && npm run build     # → out/
cd src/vscode/extension && npm run package # → .vsix
```

### Step 4: Package to dist/
```bash
cd src/figma/plugin/out && zip -r ../../../../dist/cloud-architect-kits-figma-plugin.zip .
cd src/powerpoint/add-in/out && zip -r ../../../../dist/cloud-architect-kits-powerpoint-addin.zip .
cd src/google-slides/addon/out && zip -r ../../../../dist/cloud-architect-kits-google-slides-addon.zip .
cd src/drawio/iconlib/out && zip -r ../../../../dist/cloud-architect-kits-drawio-iconlib.zip .
cp src/vscode/extension/*.vsix dist/
```

**Or:**
```bash
./scripts/build-and-release.sh
```
